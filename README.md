# Мои документы — офлайн-кошелёк документов РФ

Локальный справочник реквизитов документов РФ в формате пластиковой карты ID-1.
Приложение не является официальным документом и не заменяет бумажный или
государственный цифровой документ.

## Возможности

- Документы: паспорт РФ, загранпаспорт, СНИЛС, ИНН, ВУ, СТС, ПТС/ЭПТС,
  ОСАГО, КАСКО, ОМС, ДМС, свидетельство о рождении, банковские реквизиты,
  своя карточка.
- Карточки в формате ID-1 (`1.586:1`): гильош-паттерн, цветовая полоса,
  аватар с инициалами, контуры «печати», декоративный штрихкод.
- Поиск, фильтры по категориям, сортировка (дата / категория / название).
- Маски ввода с `VisualTransformation` + `OffsetMapping`: в состоянии только
  цифры, курсор не прыгает.
- Копирование полей, «поделиться текстом» по выбранным полям, QR-код, фото
  документа (шифруется и прикрепляется к карточке).
- Валидация обязательных полей и полноты маски перед сохранением.

## Безопасность

- Нет разрешения `INTERNET` и сетевых библиотек — данные физически не покидают устройство.
- Вход по PIN-коду (PBKDF2-SHA256, соль) и отпечатку пальца (`BiometricPrompt`).
- Шифрование AES-256-GCM с ключом в Android Keystore; настройки — `EncryptedSharedPreferences`.
- `FLAG_SECURE` включён по умолчанию, отключается тумблером в настройках.
- Блокировка хранилища при уходе в фон (`onStop`).
- Резервная копия — один файл, зашифрованный отдельным паролем (SAF), с проверкой
  размера после записи и расшифровкой на импорте.

## Маски

| Поле | Ввод | Отображение |
|---|---|---|
| Даты | 8 цифр | `13.01.2002` |
| Серия и номер паспорта | 10 цифр | `0000 000000` |
| Код подразделения | 6 цифр | `000-000` |
| СНИЛС | 11 цифр | `000-000-000 00` |
| ИНН | 12 цифр | `000000000000` |
| ВУ / СТС / ПТС | 10 цифр | `00 00 000000` |
| Телефон страховой | 11 цифр | `+7 (000) 000-00-00` |
