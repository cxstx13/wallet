# Мои документы — офлайн-кошелёк документов РФ (v2.0)

Личный офлайн-справочник реквизитов документов РФ в минималистичном стиле Apple Wallet.
Приложение не является официальным документом и не заменяет государственные сервисы.

## Что в v2.0

- Новая дизайн-система: графитовый тёмный фон `#0B0D12`, молочно-серый светлый `#F4F6F9`, отступы `20.dp`,
  мягкие плашки полей `14.dp` без рамок вместо `OutlinedTextField`.
- Премиальные карточки: многослойный градиент, блик, «шум», векторный бейдж типа документа, моноширинный номер.
- Тактильный отклик (`HapticFeedback`) на тап по карточке, копирование, пилюли действий и чипсы.
- Фиксированные формы документов РФ: названия полей не редактируются, кроме «Своей карточки».
- ФИО разбито на `Фамилия`, `Имя`, `Отчество (при наличии)` с автозаглавными буквами.
- `Пол` — переключатель `Мужской / Женский`; категории ВУ — чипсы `A…M`.
- Маски ввода через `VisualTransformation` + `OffsetMapping`: в состоянии только цифры, курсор не прыгает.
- Дата: ввод 8 цифр → `13.01.2002`, плюс выбор из календаря по иконке справа.
- Бэкап: `openOutputStream(uri).use { write; flush }`, проверка непустого списка, понятные ошибки пароля,
  принудительное обновление списка после импорта и Toast «Восстановлено документов: N».
- Настройки: тумблер «Запрет скриншотов (FLAG_SECURE)», по умолчанию включён.

## Маски

| Поле | Ввод | Отображение |
|---|---|---|
| Даты | `13012002` | `13.01.2002` |
| Серия и номер паспорта | 10 цифр | `0000 000000` |
| Код подразделения | 6 цифр | `000-000` |
| СНИЛС | 11 цифр | `000-000-000 00` |
| ИНН | 12 цифр | `000000000000` |
| ВУ / СТС / ПТС | 10 цифр | `00 00 000000` |
| Телефон страховой | 11 цифр | `+7 (000) 000-00-00` |

## Сборка

1. Запушьте файлы в ветку `main`.
2. Workflow `Build APK` соберёт `app-debug.apk`.
3. Скачайте артефакт `wallet-debug-apk` со страницы запуска Actions.

Локально (при наличии Android SDK): `gradle :app:assembleDebug`.

## Структура

- `data/model` — модели карточек, шаблоны документов РФ, типы полей.
- `data/repo` — зашифрованное JSON-хранилище и шифрованные фото.
- `security` — PIN, биометрия, Keystore-шифрование, резервные копии.
- `ui/input` — маски ввода (`VisualTransformation`, `OffsetMapping`).
- `ui/components` — дизайн-система: поля, пилюли, карточки, QR.
- `ui/screens` — главный экран, детали, редактирование, настройки, «О приложении».
