# Мои документы — офлайн-кошелёк документов РФ

Личный офлайн-справочник реквизитов документов РФ в стиле Apple Wallet.
Приложение не является официальным документом и не заменяет государственные сервисы.

## Возможности

- Карточки: паспорт РФ, загранпаспорт, СНИЛС, ИНН, ВУ, СТС, ПТС/ЭПТС, ОСАГО, КАСКО, ОМС, ДМС, свидетельство о рождении, банковские реквизиты, свои карточки.
- Стопка карточек, поиск, фильтры по категориям, маскирование номеров, копирование в 1 тап.
- Поделиться выбранными полями, QR-код документа, вложения-фото.
- PIN-код + отпечаток пальца, блокировка при сворачивании, FLAG_SECURE (без скриншотов).
- Шифрование: AES-256-GCM (Android Keystore), EncryptedSharedPreferences.
- Экспорт/импорт зашифрованного паролем бэкапа через SAF.
- Строго офлайн: нет разрешения `INTERNET` и сетевых библиотек.

## Сборка в GitHub Actions

1. Запушьте файлы в ветку `main`.
2. Workflow `Build APK` соберёт `app-debug.apk`.
3. Скачайте артефакт `wallet-debug-apk` со страницы запуска Actions.

Локальная сборка (при наличии Android SDK): `gradle :app:assembleDebug`.

## Структура

- `data/model` — модели карточек, шаблоны документов, маски ввода.
- `data/repo` — зашифрованное JSON-хранилище и шифрованные фото.
- `security` — PIN, биометрия, Keystore-шифрование, бэкап.
- `ui` — Compose-темы, компоненты, экраны.
